# FinLite
Zero-dependency Kotlin Android app. Enter current and prior period figures; it computes margins, EBITDA, interest cover, current ratio, gearing, net debt/EBITDA, ROE/ROA, EPS, receivable days and cash conversion, plus risk flags. Inputs are saved on-device; nothing is sent anywhere.
Build: open in Android Studio (it adds the Gradle wrapper), then Build > Build APK, or run `gradle assembleDebug`. APK: app/build/outputs/apk/debug/app-debug.apk
The "Sample" button loads the Atlas Power FY2011 / FY2010 figures.
