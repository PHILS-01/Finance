FinLite for Windows (single C# file, no dependencies)
1. Double-click build.bat. It uses the C# compiler already inside Windows 10/11 and creates FinLite.exe (about 20 KB).
2. Run FinLite.exe. Enter current and prior figures in one unit, click Analyse. "Load sample" fills Atlas Power FY2011/FY2010.
Inputs are saved to %AppData%\FinLite\inputs.txt. Nothing is sent anywhere.
